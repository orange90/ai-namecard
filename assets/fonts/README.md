# FoloCard font

`folocard_source_han_sans_cn_16.c` is a one-bit LVGL font generated from
Adobe's Source Han Sans CN Regular. It contains printable ASCII plus every
character representable by GB2312, covering the fixed interface and common
Simplified Chinese profile names while keeping the application within the
three-megabyte install limit.

Source: [Adobe Source Han Sans](https://github.com/adobe-fonts/source-han-sans/tree/release/SubsetOTF/CN)

License: SIL Open Font License 1.1; see `LICENSE-SourceHanSans.txt`.

The generated font uses 16 pixels, one bit per pixel, no compression, no
prefilter, and no kerning. Characters outside GB2312 display the missing-glyph
marker.
