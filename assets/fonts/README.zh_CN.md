# FoloCard 字体

`folocard_source_han_sans_cn_16.c` 是由 Adobe 思源黑体 CN Regular 生成的
1 位 LVGL 字体。它包含可打印 ASCII 和 GB2312 能表示的全部字符，可覆盖固定界面
以及常见简体中文昵称，同时让应用继续满足三兆字节安装上限。

来源：[Adobe Source Han Sans](https://github.com/adobe-fonts/source-han-sans/tree/release/SubsetOTF/CN)

许可：SIL Open Font License 1.1，见 `LICENSE-SourceHanSans.txt`。

生成参数为 16 像素、每像素 1 位、无压缩、无预滤波、无字距调整。GB2312 之外
的字符显示缺字标记。
